# SimpleTranslator

面向游戏和桌面应用的 Windows 截图翻译工具，支持单次框选翻译和文字反向翻译。

本仓库用于发布编译好的程序、使用说明和更新记录，不存放应用源代码。

## 下载

在本仓库右侧的 **Releases** 中打开最新版本，下载发布附件中的程序。

首个编译版本尚未发布，下载文件名称和安装说明以对应版本的 Release 页面为准。

## 功能

- **框选翻译**：选择屏幕区域，本地 OCR 识别后进行翻译，将译文覆盖显示在本次截图的位置。
- **双语显示**：同时显示原文和译文；紧密排列的文字可自动增加行距，减少重叠。
- **反向翻译**：输入文字，按回车翻译；简洁模式下译文自动复制到剪贴板，也支持鼠标选中后手动复制。
- **简洁 / 专业模式**：小工具条或完整截图与诊断界面，点击切换。
- **多语言**：可选择简体中文、繁体中文、英语、日语、韩语等语言。
- **多种翻译服务**：Gemini API、DeepSeek API、百度大模型翻译、ChatGPT 订阅授权通道和 Google 免费翻译。
- **外观与快捷键**：浅色、深色、跟随系统，自定义框选和反向翻译快捷键。
- **托盘运行**：最小化后进入系统托盘，可从托盘恢复窗口或退出程序。
- **单实例保护**：避免重复启动多个翻译器。

## 快速使用

1. 启动程序，在设置中选择翻译服务，按该服务要求填写密钥或完成授权。
2. 选择原文和目标语言；原文可以使用自动识别。
3. 点击“框选翻译”，拖动鼠标选择需要翻译的屏幕区域；框选时可按 Esc 或右键取消。
4. 等待译文显示；按 Esc 关闭截图覆盖。需要同时查看原文时，勾选“双语显示”。
5. 点击“反向翻译”，输入文字后按回车；再次点击反向翻译入口或按其快捷键可收起窗口。

按钮上的快捷键标注以当前设置为准。本程序不持续识别画面，也不会自动向游戏发送消息。

## 配置与数据

- OCR 在本机进行。使用在线翻译服务时，识别出的文字或手动输入的文字会发送到你选择的服务；当前文字翻译通道不上传整张截图。
- API 服务的费用、可用地区和限额由服务提供方决定。ChatGPT 订阅授权通道是否可用取决于账号权限和服务端支持。
- Gemini 免费配额提醒是本程序的本地请求统计，不是官方账户余额，也不包含其他软件或设备的使用量。
- 编译版本的设置、授权信息和日志保存在当前 Windows 用户的本地应用数据目录，不应作为发布附件上传。
- 请不要在问题反馈中公开 API Key、授权令牌或含私人聊天内容的截图。
