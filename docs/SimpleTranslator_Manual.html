1　第一次使用：先完成这三步

本软件提供框选翻译和反向翻译，不会持续扫描画面，也不会自动向游戏发送消息。软件截图来自隔离的演示配置，不含真实账号或密钥。

  1. 打开程序，进入「设置 → 服务与模型」，选择翻译服务。Google 免费翻译无需 Key；其他服务按后面章节配置。
  2. 选择截图原文和译文语言；不确定原文语言时用「自动识别」。
  3. 点「框选翻译」拖动鼠标选择文字，或点「反向翻译」输入文字。

单 EXE 首次启动要释放运行文件，通常比后续启动慢，不要反复双击。已在运行（包括托盘状态）时，第二次启动会提示已有实例。

2　主窗口：每个按钮的用途

按钮 / 区域怎么用
框选翻译开始一次截图框选；按住鼠标左键拖出矩形，松开后识别并翻译。按钮同时标注当前全局快捷键。
反向翻译打开文字输入窗口。重复点击按钮或重复按快捷键可关闭该输入窗口。
左侧语言框截图原文语言。「自动识别」适合不确定时使用；识别不好时可指定语言再试。
→ 右侧语言框截图译文的目标语言，例如简体中文、英语、日语。反向翻译的语言另行设置。
双语显示未勾选只显示译文；勾选后原文在对应译文上方，原文字号比译文小 2 号。密集多行会自动增加截图行距。
简洁 / 专业胶囊点整块任意位置切换，蓝底白色加粗文字表示当前模式。简洁版显示原位置覆盖；专业版显示原图、译图、OCR 和调试信息。
设置配置翻译服务、两个快捷键、Gemini 配额提醒、外观与自动更新。
下方模型摘要显示当前服务及模型。Gemini 额外显示今日尝试次数和剩余估算；悬停可看统计说明。
标题栏 — / ×最小化进入托盘，不继续占任务栏；关闭主窗口退出软件。窗口不能拖边框改大小，可拖标题栏移动。

3　框选翻译、覆盖与查看原文

  1. 点「框选翻译」，主窗口临时隐藏，进入框选界面。
  2. 拖动矩形包住真实文字，尽量不框入无关区域。框选时按 Esc 或右键取消。
  3. 等待本地 OCR 和翻译服务返回。简洁版在原截图位置显示覆盖结果。
  4. 想看源画面，按 Esc 关闭覆盖；想对照原文与译文，提前勾选「双语显示」。

覆盖的是本次截取的静态画面，不修改游戏，也不会随游戏滚动。译文字号按原文尺寸估算；翻译变长或双语显示会改变排版，不保证所有游戏字体完全一致。

当前没有单独的「只看原文」切换按钮。专业版同时显示原图与译图；简洁版通过 Esc 退出覆盖看到源画面。

4　专业版：对照、保存与调试

按钮 / 区域怎么用
打开图片选择本机已有图片进行一次 OCR 和翻译，不需要重新截屏。
翻译服务下拉框切换当前服务；需要密钥或授权的服务应先配置。
翻译参数 / 附加要求打开设置入口，再进「服务与模型」调整模型、推理与附加翻译要求。
两小批并发当前用于 ChatGPT 订阅的截图翻译，将文字分成两小批并行请求。增加请求次数，不保证所有内容更快。
原始截图 / 翻译结果左侧原图、右侧译图；超出区域时用滚动条查看。
保存图片保存已生成的翻译图片到本机，不是保存游戏视频。
复制译文复制本次有效译文的纯文字，可手动粘贴到其他软件。
OCR 原文先检查有没有漏字或错字，再判断是不是模型翻译的问题。
耗时 / 调试日志检查 OCR、请求和返回等阶段耗时，区分识别与网络等待。反馈前检查并打码。

5　反向翻译：输入、回车与复制

  1. 打开反向翻译，在上框输入文字。
  2. 按 Enter 开始翻译。中文输入法选词时，先确认候选词，再按一次回车。
  3. 成功返回后在下框显示译文，并自动复制；在游戏或其他软件按 Ctrl+V 手动粘贴。
  4. 也可用鼠标选中下框部分文字，按 Ctrl+C 手动复制。
  5. 按 Esc 或重复按反向翻译快捷键关闭窗口。

浅灰提示是占位文字，不会发送给模型。简洁版没有额外操作按钮；如要修改反向翻译语言，先切专业版，在其输入窗口里选语言，再切回简洁版。

按钮 / 区域怎么用
原文 / 目标语言设置反向翻译方向，例如简体中文 → 英语，与截图语言分开。
翻译 · Ctrl+Enter点击或按 Ctrl+Enter 翻译；专业版普通回车用于换行。
粘贴将剪贴板文字插入输入框光标处。
清空清空输入框。
复制译文完整复制当前译文；选中部分文字 Ctrl+C 仍可用。
翻译后自动复制专业版按勾选决定是否自动复制；简洁版固定自动复制。

6　设置：快捷键、外观与配额

设置项用途
服务与模型打开引擎配置，选择服务、填写密钥或完成账号授权。
框选 / 反向快捷键分别修改两个入口的全局快捷键；点击录入框后直接按组合键，再保存。
Gemini 配额填写项目统计组、模型与每日限额，做本地估算提醒。
外观浅色、深色、跟随 Windows 系统设置；选择后直接应用。
启动时检查 / 检查勾选则启动检查更新；检查按钮打开更新窗口，不会未经确认直接替换程序。

设置期间暂停全局快捷键，关闭设置后恢复。Esc 保留用于取消，不能设成业务快捷键。建议组合键，避免游戏输入时误触；两个入口不能设成同一个快捷键。

同一 Google 项目的不同 Key 请用同一个「项目统计组」，各模型分别设置限额，按 AI Studio 后台当前值填写。程序默认 500 等数值不代表官方保证。

只统计本程序尝试，包含失败、重试、补译，不含其他软件或设备。达到 80% 提醒，按美国太平洋时间午夜换日；每日次数没用完，也可能触发每分钟请求或 Token 限流。

7　引擎配置：字段和底部按钮

字段 / 按钮说明
翻译服务Google 免费翻译、ChatGPT 订阅、Gemini API、DeepSeek API、百度大模型翻译。
获取 API Key ↗打开当前服务的官方申请网页，相应 API 服务下可见。
API Key / Secret填写与服务及鉴权方式匹配的凭据，不填网站账号密码。
显示临时显示隐藏的密钥；截图或反馈前关闭。
模型选账号实际可用的模型 ID；预设列表不保证你的账号能调用，也不保证型号仍开放。
推理支持时可选。翻译可优先低推理减少等待；Gemini 的最低不一定完全关闭思考。不支持时禁用。
Base URL一般保留默认。不要随意改成第三方网站，避免把 Key 与原文发到错误服务器。
附加翻译要求补充术语、风格，如“冒险岛语境；保留玩家昵称；译文简短自然”。不要要求额外解释或改变块编号，以免破坏对应。Google 免费翻译不使用大模型提示词。
测试连接使用内置三行英文真实测试，会消耗相应额度，不发送当前截图。
保存并应用保存配置并切换服务。测试成功后仍要点此按钮；直接关闭不应用修改。

8　Gemini：获取 API Key 并接入

1打开 AI Studio

进入 Google AI Studio → API Keys ↗，登录自己的 Google 账号，首次使用按页面接受条款。

2选择或导入项目

选已有项目，或按页面创建项目。已有 Cloud 项目未显示时，在 Projects 页面导入，然后回 API Keys。

3创建密钥并复制

点 Create API key / 创建 API Key，选择对应项目。复制生成的 Key，妥善保管，不公开到仓库、截图或聊天。

4回软件填写

设置 → 服务与模型 → Gemini API；粘贴 Key，选择账号可调用的模型，保留默认 Base URL。

5测试、保存、设提醒

测试连接成功后保存并应用。需要配额提醒，再按项目后台填写统计组、模型每日限额。

操作路径示意图，依据官方资料整理，不是官网截图。网页按钮可能随更新变化。

Gemini 网页 / App 的 Pro 会员与 AI Studio API 是不同入口，会员额度不能当作 API 免费额度。能创建 Key 不代表所有模型免费；权限、额度与计费以项目后台为准。出现没有计费账号时，先确认是在用免费层还是开启付费计费，不要盲目绑定或充值。

官方参考：Key 与项目管理 · 限流 · API 计费

9　DeepSeek：创建 API Key 并接入

1登录开放平台

打开 DeepSeek → API Keys ↗，注册或登录账号。

2创建 API Key

在 API Keys 页面创建密钥，按页面填备注，如 SimpleTranslator。复制并保管 Key。

3确认余额与权限

在开放平台查看可用余额、额度、模型权限。网页聊天可用不代表 API 有余额。

4选择服务并填 Key

软件选 DeepSeek API，粘贴 Key，按官方当前文档与账户权限选模型，保持默认地址。

5测试并应用

测试成功后保存。余额或权限错误应在开放平台处理，不必反复修改 OCR。

操作路径示意图，不是官网截图。

官方参考：首次 API 调用与服务地址。模型、价格和余额政策以实时后台为准。

10　百度大模型翻译：两种凭据不要混填

1进入翻译开放平台

打开百度翻译开放平台 ↗，登录百度账号，按页面完成开发者信息与所需认证。

2开通“大模型文本翻译”

在我的服务或开通入口选择大模型文本翻译。不要只开通通用文本翻译，也不要去千帆平台找替代 Key。

3获取对应凭据

路径 A：开发者信息 → APPID 与密钥 Secret。路径 B：API Key 管理 → 创建用于大模型文本翻译的 API Key。以后台实际支持为准。

4在软件选匹配鉴权

A 选 APPID＋密钥：下方 APPID、上方 Secret。B 选 API Key：上方填 API Key。Secret 和 API Key 不能互换。

5测试并保存

使用固定模型 llm，默认地址不改。失败时检查服务状态、凭据和额度，记录完整错误码。

操作路径示意图，不是官网截图。

APPID 是应用标识，不是密码；Secret 与 API Key 均为敏感凭据但不能互换。附加要求可补充术语与风格，不保证逐字执行。

官方参考：大模型文本翻译与开通入口，认证要求、额度与服务状态以后台为准。

11　ChatGPT（订阅额度）：授权，不填 API Key

1选择订阅入口

设置 → 服务与模型 → ChatGPT（订阅额度）。当前界面不提供独立 ChatGPT API Key 服务。

2登录 / 重新授权

点击按钮，在浏览器登录自己的账号并授权。不要把账号密码或浏览器 Cookie 粘贴到 Key 栏。

3等待回调，选可用模型

等待软件获取授权账号的模型列表，选实际返回的可用模型，不凭名称猜权限。

4测试并保存

测试成功后保存。账号权限、授权范围和服务端支持决定是否能调用；登录不等于无限额度。

软件授权路径示意，不是官网截图。

按钮 / 区域用途
账号下拉框切换已添加账号，再获取该账号模型。
登录 / 重新授权发起当前账号登录或更新授权，等待浏览器回调。
添加账号授权另一账号，不是创建 API Key。
刷新模型重新查询账号可用模型。
退出登录清除本机登录并尝试撤销远端授权；未确认撤销时去 ChatGPT 设置断开应用。
查看用量打开 ChatGPT 用量网页，不是 Gemini 的本地估算。
取消当前登录停止正在等待的登录，不等同于注销已授权账号。

官方参考：Sign in with ChatGPT · 身份与推理权限区别。本文只说明软件入口，不代表软件已获官方认可或所有订阅均可使用。

12　托盘、更新与配置

按钮 / 区域用途
重新检查再次查询 GitHub 正式发布版本，网络不可达时稍后重试。
发布页面打开 Releases 查看说明和附件。
下载并更新发现支持的新版本后启用，确认后下载、校验并重启。先完成翻译或框选任务。
托盘图标 / 菜单恢复主窗口，或打开框选翻译、反向翻译、退出。重复运行 EXE 不会创建第二份实例。

打包版用户配置和用量保存在 %LOCALAPPDATA%\SimpleTranslator。EXE 同目录缓存用于加速启动，不是译文记录；移动程序或删缓存可能重新解压。

更新依赖仓库已发布匹配的正式 Release 与附件；勾选检查不会产生新版本。本说明书不表示新版已上传。

13　常见问题、隐私与反馈

问题先检查什么
没有识别出文字先看 OCR 原文；只框真实文字，提高清晰度，小字可放大源窗口再试。组件加载失败按提示处理。
翻译很慢看专业版耗时。OCR 快、HTTP 等待长通常是网络或服务等待；减少无关文字、降低推理。不要只凭总耗时认定 OCR 慢。
Key 无效 / 无权限服务是否选错、凭据有无空格、项目有无权限、模型是否可用、服务是否开通；不要乱改 Base URL。
百度错误码保留完整返回码；核对大模型服务已开通、鉴权匹配、额度有效，不要都归因 OCR。
ChatGPT 身份不匹配取消后从软件重新发起授权；不要复用其他应用回调或改身份参数，仍失败提交打码日志。
没有自动复制简洁版成功后应自动复制；专业版检查自动复制勾选。可手动选中 Ctrl+C。失败信息不当有效译文复制。
窗口找不到检查托盘隐藏图标区，恢复已有窗口，不要反复启动。

隐私：OCR 在本机识别；翻译发送识别文字或输入文字给所选服务，不上传整张截图。不要框选密码、证件或私密聊天。Key 保存在本机，界面隐藏不等于所有配置加密；反馈前检查并打码。

反馈：在 GitHub Issues 写版本、服务、步骤、打码截图和必要耗时日志，不上传配置文件、Key 或登录凭据。
